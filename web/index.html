Install the Helrig Box firmware

Open this page in desktop Chrome or Edge.
Safari, Firefox and phones cannot install firmware from a web page.
1

Plug the board into this computer

Use the board's USB-C port (not the USB-A one) and a cable that carries data.

2

Press Install

When your browser asks, choose USB Single Serial.

3

Wait about 2 minutes

Keep this tab open and the cable plugged in. The board restarts by itself.

✓

Having trouble?
  • Nothing in the list: try another cable, or unplug and replug the board.
  • Cannot connect: hold BOOT, tap RESET, release BOOT, then press Install again.
  • Close any program that is using the board's serial port.
  • Linux: your user must be in the dialout group.
